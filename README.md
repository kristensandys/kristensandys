# Hi, I'm Kristen

I am interested in bioinformatics, cancer genomics, and
transcriptional regulation. 

During my MSc internship, I developed research scripts to
investigate transcriptional and epigenomic differences
between NPM1-mutated AML groups.

## Featured research

[NPM1 AML Regulatory Analysis](https://github.com/kristensandys/NPM1-AML-Regulatory-Analysis)

Documented R workflows for H3K27ac differential-peak analysis,
candidate-gene annotation using rGREAT, and KEGG pathway
enrichment, with example input and a representative figure.

## Technical experience

- R and Bash scripting
- Downstream RNA-seq and ChIP-seq analysis
- Genomic annotation, pathway enrichment, and visualization
